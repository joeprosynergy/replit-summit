# Summit Portable Buildings website

The public site is [summitbuildings.com](https://summitbuildings.com). It is a Next.js App Router app on Vercel. Plyntr maintains it.

Read `CLAUDE.md` before changing a page, a URL, or tracking. That file is the map. This file is how to run the app on your machine.

## Run locally

Install Node.js. Then, from this folder:

```sh
npm i
npm run dev
```

The dev server prints a local URL. Do not deploy from a local edit unless the person asked you to deploy.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase for page content
- Vercel for the live site

React draws the pages. The product is the Next.js app.
